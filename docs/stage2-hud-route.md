## 1. 조작

HUD에서 마우스는 시선만 바꾼다. HUD 항목은 클릭할 수 없고, 우주복 손 조작기(다이얼 + 버튼 2개)와 음성을 키보드로 대신한다. 근거는 [hud-design-basis.md](hud-design-basis.md).

| 우주복 입력 | 키 | 동작 |
| --- | --- | --- |
| 이동 | `W` (누르는 동안) | 확정 경로를 따라 전진. 도보 1.4 m/s, 로버 3.5 m/s (둘 다 모의). 복귀 중에는 기지 쪽으로 전진 |
| 로버 | `E` | 탑승 / 하차 |
| 배속 | `Shift` + `W` (로버 탑승 중) | ×4. 체험 시간 단축용 |
| 다이얼 회전 | 마우스 휠, `[` `]` | 카드 안에서 강조 항목 이동 |
| 다이얼 누름 | `M` | 미니맵 켜기 / 끄기 |
| 버튼 1 | `1` (`Enter`도 같음) | 강조 항목 실행: 도착 확인, 작업 완료, 촬영 마킹, 메모 열기, 복귀 개시, 기지 지시 확인, 임무 종료 |
| 버튼 2 | `2` | 카드 접기/펴기. 카드가 없을 때는 기본 → 우주복·임무 상태 층 → 부가 정보 숨기기 → 기본 순서로 돈다 (통합본에서 바뀜) |
| 음성 | `V` 누르는 동안 | 음성 메모 받아쓰기 (브라우저 음성 인식, 성능 미검증). 안 되면 "음성 대체 입력(데모)" 칸에 타이핑. 메모 화면이 아닐 때는 "상세" 한 단어만 듣고 우주복·임무 상태 층을 여닫는다 (통합본에서 추가, 실제 음성 인식은 미검증) |
| (앱) | `Esc` | 마우스 커서 풀기 → 화면 오른쪽 위 `역할 전환` |

### 임무 흐름

이동 → 도착 알림 → (버튼 1) 관찰 → 작업 항목(관찰 대조, 촬영 마킹, 음성 메모)을 다이얼과 버튼 1로 완료 → `복귀 개시` 실행 → 같은 경로로 복귀 → 기지 도착 → (버튼 1) 임무 종료. 도착과 관찰 시작, 기지 도착과 임무 종료는 서로 다른 상태다. 무엇을 확인해도 복귀가 자동으로 시작되지는 않는다.

기록에는 임무 시계, 경로 위치, 좌표(모의 위치를 지도 좌표로 바꾼 값)가 자동으로 붙고 PAD 홈의 "현장 기록"에 나타난다. 교신이 끊긴 동안 만든 기록은 다시 이어질 때 전송된다. PAD 홈의 `HUD로 복귀 지시 전송`은 HUD에 카드를 띄울 뿐이며 전송·HUD 수신·대원 확인·실행(또는 보류)이 따로 표시된다.

### 배속의 의미

배속은 로버가 빨라지는 것이 아니라 **데모 시간 압축**이다. 임무 시계, 산소, 누적 방사선, 이동 거리가 모두 같은 비율(×4)로 진행하고 로버 속도 표시는 3.5 m/s 그대로다. 도보 중에는 적용하지 않는다(요청이 로버 구간이었고, 도보 구간은 기지~로버 약 17 m로 짧다). 도착하면 자동으로 ×1로 돌아간다.

## 3. 목적지와 경로의 자료 근거

### 목적지

- NASA 시료 목록: 시료 25 "Sapphire Canyon", Cheyava Falls, Neretva Vallis, 밀봉 sol 1215 (2024-07-21). <https://science.nasa.gov/mission/mars-2020-perseverance/mars-rock-samples>
- M20 waypoints: 로버는 site 56 / drive 0 (77.30519089°E, 18.49748444°N)에 sol 1210에 도착했고 다음 주행은 sol 1219다. sol 1215는 이 정지 기간 안이다.
- 따라서 목적지는 **채취 때 로버가 서 있던 위치**다. 암석 자체의 좌표는 공개된 것을 찾지 못했다. 암석은 로봇 팔이 닿는 범위(수 m) 안에 있었을 것이나 방향·거리는 확인하지 않았다. 로버 위치 자체의 오차 값도 확보하지 못했다.

### 경로

- 출처: `M20_traverse.json` (NASA/JPL MMGIS 공개 레이어). Perseverance가 sol 1175~1185에 실제로 달린 선의 꼭짓점 326개(평균 간격 1.1 m, 최대 7.9 m).
- 사용 구간: `52_7624→53_0→53_130→54_0→54_702→54_866→54_1010`. 공개 길이와 직접 계산한 길이가 구간마다 3 cm 안에서 일치한다.
- 경로 344 m 중 실외 334 m. 그중 326 m가 실제 주행선이고, 8.0 m가 연결 구간이다(기지 경사로 끝 → 주행선 7.1 m, sol 1185 정지점 → sol 1210 정지점 0.9 m).
- 주행선의 처음 17개 꼭짓점(약 19 m)은 가상 기지 아래를 지나므로 건너뛴다. 기지는 sol 1174 로버 정지점 위에 놓은 가상 배치다.
- 경사(5 m 구간, 1 m DTM): 브라우저 계산 최대 12.7°, Python 독립 계산(주행선 전체) 최대 12.1°, 평균 3.2°.
- 최소비용 경로 탐색은 하지 않았다. 실제 주행선을 그대로 쓰는 편이 가정이 적다.
- 한계: 로버가 지나간 땅일 뿐 사람 보행이나 유인 로버 주행의 안전성을 검증한 것은 아니다. 데모 로버는 이 선의 오른쪽 2.2 m 평행선을 달리며, 그 선의 주행 가능성은 확인하지 않았다. 고도는 1 m DTM 보간값이다.

재현: `python3 -I tools/terrain/extract_route.py <cache> public/data/jezero` → `route.json`.
