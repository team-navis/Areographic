# Stage 1 데이터·자산 기록

2026-11-14 작성, 11월 15일 통합 3D 기지 보행 구현에 맞춰 갱신. 1~5절은 `demo/3d-stage1`의 관측 자료·모의 모델을 기록하고, 6절은 후속 브랜치에서 보관하는 기지 콘셉트 참고 이미지, 7절은 현재 3D 기지·보행 구현을 기록한다. 재현 스크립트는 `tools/terrain/extract_jezero.py`, `tools/assets/fetch_polyhaven.py`이며, 지형 산출물의 크기·SHA-256·좌표 기준은 `public/data/jezero/terrain.json`에 있다.

## 1. 실제 관측 지형 (확보)

| 항목 | 값 |
| --- | --- |
| 근거리 DTM | Mars 2020 TRN HiRISE DTM 모자이크 `JEZ_hirise_soc_006_DTM_MOLAtopography_DeltaGeoid_1m_Eqc_latTs0_lon0_blend40.tif` (USGS Astrogeology, 원본 1.84 GB) |
| 근거리 영상 | 같은 세트의 정사영상 `JEZ_hirise_soc_006_orthoMosaic_25cm_Eqc_latTs0_lon0_first.tif` (원본 7.36 GB, 8-bit 단색) |
| 원거리 DTM / 영상 | CTX `JEZ_ctx_B_soc_008_DTM_..._20m` (9.7 MB) / `JEZ_ctx_B_soc_008_orthoMosaic_6m` (36 MB) |
| 내려받은 범위 | HiRISE: 640 m × 640 m 창만 HTTP range 요청으로 읽음(전체 미러링 안 함). CTX: 파일 전체를 받아 8 km × 8 km 창을 잘라냄 |
| 창 범위 | 경도 77.29959°~77.31039°E, 위도 18.49081°~18.50160°N (planetocentric) |
| 해상도·단위 | DTM 1 m/px(HiRISE), 20 m/px(CTX). 높이 m, MOLA areoid 기준. 영상 25 cm/px, 6 m/px |
| 좌표계 | Equirectangular(lat_ts 0, lon0 0), Mars 2000 Sphere IAU, R = 3,396,190 m. `X = R·λ`, `Y = R·φ` |
| NoData | HiRISE 창 0개, CTX 창 0개 |
| 정합 | DTM과 정사영상은 같은 TRN 세트로 원점·투영이 같다(GeoTIFF 태그로 확인). 서로 다른 출처를 손으로 맞춘 것이 아니다 |
| 로버 위치 | `M20_waypoints.json` (NASA/JPL MMGIS 공개 레이어). sol 1171~1220의 21개 정지점 사용 |

로컬 좌표: 원점은 로버 정지점 site 52 / drive 7624 (sol 1174, 77.30628°E 18.49500°N). `east = (X − X0)·cos(φ0)`, `north = Y − Y0`, 3D는 `x = east, z = −north, y = 고도 − 원점 고도`. PAD 지도와 3D 세계가 같은 `toWorld/toEqc` 함수를 쓴다(`src/world/terrain.js`).

### 검증한 것

- 기지 원점 ↔ Cheyava Falls 정지점 거리: 로컬 좌표 159.436 m, 미션 격자(easting/northing) 159.440 m, 구면 대원거리 159.436 m. 세 방법이 4 mm 안에서 일치한다.
- 21개 정지점에서 HiRISE DTM 값 − 미션 기록 고도(`elev_geoid`): 평균 −0.011 m, 범위 −0.093~+0.054 m. 단, 미션 고도가 같은 계열 DTM에서 나왔을 가능성이 높아 완전히 독립된 검증은 아니다. 좌표 변환이 어긋나지 않았다는 확인으로만 쓴다.
- 경사(1 m DTM): 창 전체 중앙값 8.5°, 95퍼센타일 28.2°. 기지 원점 주변 반경 10 m 평균 3.8°, 최대 9.7°.

### Cheyava Falls 위치의 한계

목적지 좌표는 **로버가 sol 1210~1218에 머문 정지점**(site 56 / drive 0, 77.30519°E 18.49748°N)이다. sol 1212 WATSON 촬영(PIA26368)과 기간이 겹친다는 것까지만 자료로 확인했다. 암석 자체의 좌표·형상은 확보하지 않았고 3D로 만들지도 않았다(도착 지점에는 표식 깃대만 있다).

## 2. 실제 자료가 아닌 것

| 구분 | 내용 |

## 4. 미확보·미사용

- Cheyava Falls 암석의 위치·형상, 현장 대조 사진 원본(PIA26368 파일은 내려받지 않음).
- Perseverance Raw Images, USGS 지질도, THEMIS/TES, 광물 지도: 이번 단계에서 사용하지 않음.
- 로버의 전체 주행 궤적(`M20_traverse`): 내려받지 않음.
- 실시간 화성 기상·우주기상, 통신 가시선, 버디 위치.
- NASA Worldview(지구 관측)와 Curiosity Mount Sharp 경로는 이 장소의 자료로 쓰지 않았다.
- 기존 stage 1에는 레퍼런스 이미지·영상을 복사하지 않았다. 후속 관제실 브랜치에 추가한 기지 이미지 기록은 6절에 있다.

## 6. Stage 2 변경 (브랜치 `demo/hud-route`)

- 2절의 "로버 정지점을 직선으로 이은 스텁" 경로는 **Perseverance 실제 주행선**(M20 traverse)으로 바뀌었다. 편도 344 m. 자세한 근거는 [stage2-hud-route.md](stage2-hud-route.md) 3절.
- 목적지 의미를 "시료 25 Sapphire Canyon 채취 기간의 로버 위치"로 구체화했다(sol 1215, NASA 시료 목록 확인).
- PIA26368 원본을 내려받아 HUD 기준 사진으로 쓴다(4절의 "내려받지 않음"은 더 이상 해당 없음). 로버 전체 주행 궤적도 확보했다.

## 8. 현재 통합 3D 기지와 실내 보행

| 항목 | 구현·범위 |
| --- | --- |
| 기하 구조 | `src/world/base.js`의 벽·천장·바닥·작업대·창문·가구·에어록·모니터 메시. 시작·관제·실내 보행·외부 탐사에서 동일한 3D 월드 사용 |
| 표면 자산 | 기존 Poly Haven 텍스처와 `src/world/habitat-materials.js`의 절차적 도장·금속·흡음재·종이 CanvasTexture. 이번 3D 전환에 새 이미지 생성 사용 없음 |
| 모니터 | 실제 3D 모니터 메시의 공유 임무·지형 요약 CanvasTexture, 접근 완료 후 DOM 상세 오버레이. CSS3D 및 별도 이미지 기지 장면을 현재 실행 경로에서 제거 |
| 보행 공간 | 방 x −4.5~4.5m / z −3~3m. 에어록 x −7.1~−4.62m / z −0.25~2.25m. 문 중심 z=1m, 폭 1.15m |
| 충돌 | 반경 0.22m의 수평 캡슐과 벽·가구 영역. 책상·의자·수납장 등 가구 영역은 `HABITAT_OBSTACLES`로 렌더링과 보행 구현이 공유 |
| 이동 | 실내 `WASD` 자유 이동, 마우스 드래그·방향키 시선. 대각선 정규화·50ms 프레임 제한·벽면 미끄러짐. 점프·중력·물리 엔진은 포함하지 않음 |
| 임무 연결 | 실내 위치를 별도로 유지하며 모니터 복귀 때 같은 보행 위치로 돌아감. 실내 보행 중 EVA 거리·시간·산소가 진행되지 않음. 에어록 출구 통과 시 고정 경로(6절의 실제 주행선 기반 경로)의 경사로 구간에 한 번 합류 |

보행 충돌과 3D 재질은 가상 기지를 탐색하기 위한 구현이다. 실제 구조물 치수 검증, 유인 거주 시설 설계, 가압·감압 또는 탐사 경로 안전성 검증을 의미하지 않는다. 현재 검증 상태와 조작은 [immersive-control.md](immersive-control.md)에 기록한다.
