## 현재 화면과 동선

기지 벽·천장·바닥·창문·작업대·가구·모니터·에어록은 실제 깊이를 가진 절차적 3D 메시입니다. 따뜻한 패널과 금속, 천 재질과 작업 조명으로 기존 기지 콘셉트의 분위기를 반영했습니다. 세 모니터와 창문을 바라보는 관제석에서 시작하고, 현장 대원 시점으로 전환하면 같은 공간의 바닥을 걸어 다닙니다. 실내 보행에는 벽과 가구의 수평 충돌을 적용합니다.

모니터에는 공유 임무·지형 자료를 그린 CanvasTexture 요약이 표시됩니다. 모니터를 클릭하거나 바라보며 `F`를 누르면 카메라가 해당 3D 모니터 앞으로 접근합니다. 접근이 끝나면 모니터에 맞춘 DOM 상세 화면을 표시해 탭·슬라이더·링크를 조작할 수 있습니다. `Esc`로 닫으면 모니터를 열기 전의 실내 위치와 시선으로 돌아옵니다. 관제석에서 연 경우에는 관제석으로 돌아갑니다.

실내 보행 위치는 EVA 경로 진행 거리와 분리합니다. 기지를 둘러보거나 관제 화면으로 전환해도 선택한 계획과 보행 위치를 유지하고, 실내 보행만으로 EVA 시간·산소를 소모하지 않습니다. 왼쪽 에어록의 외부 문을 통과하면 기존 경로의 경사로 구간에 합류하고 헬멧 HUD로 전환됩니다. 이후에는 기존 `W` 전진과 로버 `E` 탑승·하차를 사용합니다. 이미 외부로 출발한 임무에서 대원 시점으로 돌아가면 기존 외부 위치를 이어 사용합니다.

| 위치 / 관제 단축키 | 모니터 | 상세 기능 |
| --- | --- | --- |
| 왼쪽 / `1` | 과학·관측 자료 | 경로 고도 단면과 지점 슬라이더, 21개 Perseverance 정지점 상세, HiRISE/CTX/M20 원본 출처 |
| 중앙 / `2` | 경로·임무 계획 | 기존 PAD 홈, 지도 레이어, 후보지 가중치·비교·선택 |
| 오른쪽 / `3` | 대원·기지 운영 | 공유 임무 진행률·산소·이동 수단, 로버 위치·승하차 안내, 기지와 모의 범위 |

중앙 PAD의 비활성 다음 단계 메뉴는 아직 구현하지 않았습니다. 모든 모니터는 같은 임무 객체를 사용하므로 다른 화면을 열어도 목적지·진행 위치·차량 상태가 이어집니다.

탐사 HUD는 중앙 시야를 비우고 가장자리에 계기를 배치합니다. 상단에는 목적지·계획 버전과 시선/경로 방향, 하단에는 산소·경과 시간·남은 거리·진행률·현재 속도·계산 이동 시간을 표시합니다. 실제 정지 상태의 속도는 `0.0 m/s`이며, 남은 이동 시간은 남은 경로를 현재 이동 수단의 설정 속도로 나눈 값입니다. 정지·조사·귀환 시간과 지형별 속도 변화는 포함하지 않습니다. 로버 근처에서는 탑승 가능한 상황에 맞춰 `E` 버튼과 안내를 표시합니다.

**우주복·임무 상태**를 펼치면 산소 모델·이동 시간 계산 조건과 미연결 항목을 확인합니다. 심박·압력·체온·전력·통신 지연·버디 위치에 임의 숫자를 만들지 않습니다. 이 패널을 열면 이동 입력을 해제하고 포인터 잠금을 풀며, 열린 동안 `W`·`E`와 시선 이동·포인터 재잠금을 차단합니다. 패널은 센서 설명 화면이므로 EVA 시계와 모의 산소 소비 자체를 일시정지하지 않습니다. 닫으면 기존 경로·차량 상태에서 새 입력으로 이동을 이어갑니다.

실내 보행 UI에는 현재 구역, 중앙 조준점, `WASD`·드래그·방향키 안내와 해당 모니터의 `F` 진입 버튼을 표시합니다. 실내 `Esc`는 마우스 커서 해제이며 역할 전환 버튼을 대신하지 않습니다. 외부 HUD에는 실내 자유 보행 입력을 적용하지 않습니다.

입력 요소를 조작할 때는 이동·모니터 선택 단축키를 처리하지 않으며 Ctrl·Meta·Alt를 함께 누른 브라우저 단축키도 가로채지 않습니다. 창이 초점을 잃거나 마우스 잠금이 해제되면 이동 입력을 해제합니다. `prefers-reduced-motion`이 켜져 있으면 자동 시선 효과와 실내 흔들림을 끄고 기지 카메라 전환을 짧게 시작합니다. 외부 탐사자 헬멧 진입 연출 전체를 제거하는 설정은 아닙니다.

## 자료와 모의 상태

- **관측 입력:** 보관된 HiRISE 1m DTM·25cm 정사영상, CTX 20m DTM·6m 정사영상, Perseverance 정지점 기록.
- **계산 표시:** 경로 길이, 고도 단면, 지형의 5m 구간 경사. 실제 보행·차량 통과 안전성을 보장하는 경로가 아닙니다.
- **모의 상태:** 실내 위치, 외부 경로 진행, 도보 1.4m/s·로버 3.5m/s, 경과 시간과 산소. 실내·관제에서는 EVA 예산이 정지하고, 외부 HUD에서 모의 시간이 흐릅니다.
- **미연결:** 실시간 기상, 생체·우주복 센서, 기지 압력·전력, 통신 지연, 독립 버디 상태. 미연결 값을 실제 계측처럼 표시하지 않습니다.
- **기지 모델:** 실제 시설·부지가 아닌 가상 구조물입니다. 에어록 문은 위치에 따라 열리는 시각 연출이며 감압·안전 절차는 모델링하지 않습니다.

자산 출처와 좌표·고도 기준은 [stage1-data-assets.md](stage1-data-assets.md)를 따릅니다. 이번 실제 3D 전환에 새 이미지 생성을 사용하지 않았습니다. 기존 기지 콘셉트 이미지는 참고 자료로 보관하며 현재 런타임의 배경이나 방 투영에 사용하지 않습니다.

## 구현 구조

### 실내 모델과 정적 간접광 보강

벽은 접힌 외곽 플랜지와 낮아진 중앙 판, 고무 이음, 나사와 점검 표기로 구성합니다. 천장도 단차가 있는 카세트 패널과 보강재로 나누고, 환기구에는 실제 깊이를 가진 루버를 배치했습니다. 작업대는 얇은 스테인리스 상판·접힌 앞치마·안쪽 리턴·브래킷을 갖추고, 캐비닛 문과 서랍에는 틈·경첩·손잡이·잠금장치가 있습니다. 운반함은 패널·모서리 압출재·개스킷·잠금쇠·접힌 손잡이를 별도 형상으로 구성합니다. 키보드·펜통·계기·문서·낮은 의자도 같은 공간 안의 실제 메시입니다.

금속은 가구 길이에 따라 텍스처가 늘어나지 않도록 미터 단위 UV를 적용하고, 작업대와 운반함의 브러시·마찰 흔적·거칠기를 분리했습니다. 등기구에는 반투명 확산판을 모사한 발광 표면을 사용합니다. 에어록 문은 판에 창 구멍을 뚫은 형상과 양쪽 프레임·유리·손잡이를 가지며 기존 슬라이딩 동작을 유지합니다. 가구의 수평 외곽과 모니터 화면 위치는 기존 보행 충돌 영역과 동일합니다.

`habitat-irradiance.js`는 시작할 때 방과 가구의 단순화한 표면으로 고정 등기구의 확산 반사를 계산합니다. 두 번의 확산 반사를 1차 구면 조화 계수의 공간 격자로 저장하고, 재질 셰이더에서 월드 위치·법선에 따라 보간합니다. 균일하게 방 전체를 밝히던 바닥 보조광을 제거하고 가림에 따른 차이를 반영합니다. 기존 직접 조명·금속 반사·도장 거칠기 처리와 실내 GTAO는 유지하며, 실외에는 이 간접광을 적용하지 않습니다. 실내 환경 맵은 간접광 셰이더 설치 전에 캡처해 같은 반사 성분이 반복해서 들어가는 것을 피합니다.

이는 정적·저해상도 확산광 근사이며 경로 추적이나 자산별 UV 라이트맵 베이크가 아닙니다. 움직이는 문·대원의 간접 그림자나 작은 나사·배관의 반사까지 재계산하지 않으며, 가까운 접촉 음영은 직접 그림자와 GTAO가 보완합니다. 문·램프·가구 배치를 바꾸면 베이크 입력도 맞춰야 합니다. 문과 경사로는 움직이는 부모 그룹 안에서 재질별로 병합해 세부 형상을 추가하면서 드로 콜을 줄였습니다.

시작·관제·실내 보행·외부 탐사는 `src/main.js`의 동일한 Three.js scene·camera·WebGL renderer를 사용합니다. 물리적 모니터 메시를 레이캐스트로 선택하며, 벽에 가려졌거나 실내 보행 시 너무 먼 모니터는 선택하지 않습니다. 모니터의 기본 화면은 CanvasTexture이고 상세 화면은 접근 완료 후 표시하는 DOM 오버레이입니다. 현재 실행 경로에서 CSS3DRenderer와 별도의 이미지 기지 장면을 제거했습니다.

실내에서는 `src/render/habitat-renderer.js`의 GTAO 접촉 음영을 반경 0.35m로 적용합니다. MSAA 4샘플 렌더 타깃, ACES OutputPass, FXAA 가장자리 보정을 사용하고 외부 지형·헬멧 시점은 직접 렌더 경로를 유지합니다. 실내 픽셀 비율은 최대 1.5, 음영 버퍼는 그 75% 해상도입니다. GTAO 깊이 패스에서 그림자 맵을 중복 생성하지 않으며 렌더 통계는 프레임 전체를 집계합니다. 모니터 주변 발광은 절제하고, 공간 격자의 정적 확산광으로 천장·벽·가구에 반사되는 빛을 보완합니다. 이 조명은 가상 실내 연출입니다. 실내 환경 맵을 생성할 때 이전 중간 PMREM 결과와 캡처 큐브 렌더 타깃을 정리했습니다.

벽은 회백색 도장 4종과 국소적인 가장자리 마모·체결부 얼룩을 사용합니다. Poly Haven의 원본 법선·거칠기 맵을 도장·흡음재에 적용했고, 도장은 최종 거칠기 하한 0.55로 과한 플라스틱 광택을 억제합니다. 브러시드 스틸과 알루미늄은 서로 다른 거칠기·반사 특성을 사용합니다. 새 텍스처 3개의 출처·라이선스·해시는 `public/textures/polyhaven/LICENSES.json`에 기록했습니다. 이미지 배경이나 투영식 방으로 바꾸지 않았습니다.

## 다음 단계 제안

1번의 우선 작업인 실내 모델 정교화·금속 UV 밀도·정적 간접광은 이번 변경에 반영했습니다. 아래는 그 이후의 남은 개선 방향입니다.

1. **자산별 라이트맵과 실측 재질 검증.** 현재 공간 간접광은 고정 구조의 저해상도 근사입니다. 다음 품질 단계는 벽·가구별 UV2를 갖춘 저작 자산과 고해상도 정적 라이트맵, 촬영 기반 재질을 확보해 패널 이음과 넓은 면의 음영을 더 정확하게 만드는 것입니다. 저사양 GPU에서 품질 단계별 프레임 시간을 측정한 뒤 해상도와 자산 밀도를 정하는 것이 좋습니다.
2. **우주복 리깅과 손 동작.** 현재 NASA Mark III 모델은 정적 메시라 보행 주기·착석·손잡이 잡기 동작이 없습니다. 리깅과 손 접촉점을 확보한 뒤 도보·정지·승하차의 동작 전환을 연결하고, 로버 탑승 위치와 손잡이·시야가 맞는지 확인하는 순서가 적합합니다. 현재의 재질·헬멧 마감은 이 관절 동작을 구현한 것이 아닙니다.
3. **조사·기록·귀환을 잇는 임무 흐름.** 현재 외부 컨트롤러는 고정 경로 전진과 도착 판정을 제공하고 관찰·시료·임무 기록·귀환 단계는 연결하지 않았습니다. 목적지별 관측 근거를 확인하고 기록을 남긴 뒤 같은 계획의 귀환으로 이어지는 상태 전환을 추가할 수 있습니다. 단계 전환과 관제 복귀에서 기존 시간·산소·차량 위치를 보존하고, 실제 관측과 가상 조사 결과를 구분하는 것이 우선입니다.
