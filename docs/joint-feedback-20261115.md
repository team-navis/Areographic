# 공동 시연 피드백 반영 (2026-11-15)

원문: 아이데이션 메시지 1571335696562782348(사용자가 옮겨 준 내용). 같은 날 추가 지시: 관제 화면을 큰 화면 하나로, 대원은 작업이 끝나도 다시 나가면 같은 작업으로 새로 시작, 1인칭 실내에서 에어록 방향 안내.
관찰 대조(세 칸 자료·이미지·범례·관찰 항목·응답 로직)는 채원 님 검토 영역이라 바꾸지 않았다.

## 바뀐 것

- **관제 화면 하나**: 3D 기지의 모니터 3대를 16:9 큰 화면 1대(2.24 × 1.26 m, `src/world/base.js` `MONITOR`)로 바꿨다. 관제석에 앉는 모션이 끝나면 화면 전체가 시야에 들어오고, 이어서 PAD가 저절로 열린다. 열린 PAD는 위 제목 줄과 아래 줄 사이를 최대한 채운다(`main.js` `focusFrame`). 과학·운영 보조 화면은 모니터에서 뺐다(코드는 남김). 긴 기록 목록(PAD 홈 기록, ⑤ 응답 기록·전송 상태)만 안에서 스크롤된다.
- **용어**: 화면의 "돌아설 시각" → "귀환 시각". 옆에 "귀환을 시작해야 하는 기한 · 기지 도착 시각 아님"을 붙였고, 총 소요는 "기지 도착 예상"으로 적었다. 계산은 그대로다. HUD 왼쪽 아래 작은 글씨는 "귀환 시각까지".
- **반복 탐사**: 종료 후 다음 탐사를 PAD 홈·④·⑤의 "다음 탐사 계획 시작" 버튼으로, 대원은 에어록으로 다시 걸어 나가기만 하면 시작한다. 이전 임무의 기록·계획·패키지·경보는 `st.archive`에 그대로 남고, 새 임무는 시각·산소·선량·경보·계획·패키지·로버 위치를 새로 시작한다. 이전 임무의 관심 지점 표시는 장면에서 지운다.
- **입력과 음성**: 대원은 타이핑하지 않는다는 전제로 정리했다. 음성 명령창의 텍스트 입력과 메모의 텍스트 칸은 `?review`를 붙였을 때만 나오고 "검수용 · 대원 입력 아님"으로 기록한다. 음성 실패는 원인별로 보여 준다(`src/hud/voice-diag.js`): 브라우저 미지원 / 보안 연결 아님(LAN `http://` 주소에서는 브라우저가 마이크를 막음, `localhost`나 HTTPS 필요) / 마이크 권한 / 인식 이벤트(시작·말소리·결과·오류 코드·결과 없음). 메모에서 받아쓴 내용이 없으면 버튼 1이 "시연 예시 메모 · 실제 음성 인식 아님"을 `시연 예시 기록 (버튼 · 음성 아님)`으로 저장한다. 실제 음성 경로(V 누르는 동안)는 그대로다.
- **이동 중 안내**: 이동 중 나침반 아래에 한두 문장(도착 후 작업 순서와 이유, 곧 도착, 귀환 중)을 띄운다. 카드(경보·계획·패키지 등)가 뜨면 숨긴다. 실제 화성 운용 사례를 인용하지 않는다.
- **자동 이동과 로버**: 로버는 채취하러 갈 때와 복귀할 때 모두 자동으로 탄다(직접 조작 중에도 로버 옆을 지나면 탑승, 목적지에서 내렸으면 귀환 시작 때 다시 탑승, 기지 경사로에서 하차. 계획이 "도보"일 때만 타지 않음). 대원이 W로 기지를 나와 로버에 타면 목적지까지 자동 진행한다(로버 구간은 Shift와 같은 ×4 시간 단축, 시계·산소·선량도 ×4). 도착·경보·기지 도착에서 멈추고, 귀환을 시작하면 다시 자동으로 돌아오며 기지에서 자동 하차한다. W나 S를 새로 누르면 그 EVA 동안 직접 조작, 음성 "자동"으로 다시 켠다. 기본 계획의 이동 가정을 로버로 바꿔 예산과 맞췄다.
- **탐사자 바로 시작**: 관제 준비 없이 대원으로 들어가면 현재 계획 버전의 계획과 선 투영 패키지(기본 채취 지점 B)를 `시연 자동 준비 (사람 결정 아님)`로 준비한다(`auto: true`, 기록 내보내기 `demoPrepared`). 관제자가 이미 보낸 계획은 그대로 두고, 관제 전송 경로도 그대로다. 관찰 결과·생명 판정은 만들지 않는다.
- **에어록 안내**: 대원 1인칭 실내에서 바닥 화살표가 에어록까지 이어지고, 문 위에 "에어록 · 이쪽으로 나가세요"가 뜬다(화면 밖이면 그 방향 가장자리에 고정).

## 확인

- `npm test` 35개 통과(새 `tests/joint-feedback.test.mjs` 4개: 자동 진행·도착 정지, W/S 전환과 "자동" 재개, 경보 정지, 다음 탐사 초기화와 재출발).
- 브라우저(헤드리스 Chrome): 1280×720·1440×900·1920×1080 화면 맞춤, 관제 시작 → 모의 대원 종료 → 다음 탐사 → 두 번째 출발, 탐사자 바로 시작 → 계획·패키지 수신 확인 → 자동 이동 → W로 직접 조작 → "자동" 재개 → 도착 → 시료·촬영·메모(예시) → 귀환 → 기지 자동 하차 → 종료 → 걸어 들어감 → 다시 나가 EVA 2.
- 음성: 헤드리스 브라우저에서는 `not-allowed`로 실패했고 화면에 그 원인이 나왔다. **실제 마이크 인식은 확인하지 않았다.** 버튼 예시 기록은 음성 인식으로 기록되지 않는다.

## 2차 피드백 (같은 날)

- 에어록 안내 글자 대신 **화살표 아이콘**: 문 위에서 아래를 가리키고, 문이 화면 밖이면 그쪽 가장자리에서 옆을 가리킨다. 바닥 화살표는 그대로.
- **자동 진행은 꺼지지 않는다**: 로버에 타 있는 동안 W는 앞으로, S는 뒤로 자동 진행(뒤로 끝까지 가면 멈추고 W로 다시 앞으로). 도착·경보·기지 도착에서만 멈추고, 경보를 처리하면 다시 이어진다. 중간에 E로 내리면 멈추고, E로 다시 타면(또는 3.5 m 이상 떨어졌다가 로버로 돌아오면) 자동 진행이 이어진다. 음성 "수동"은 멈춤, W/S나 "자동"으로 다시 켠다.
- HUD 하단의 Select · Next · Voice · Map 줄을 없앴다. 키 안내 줄은 남기고 **3 촬영 · 4 메모**를 더했다.
- **촬영 · 메모는 우주복 버튼**: 3(또는 C) = 촬영 · 영상 마킹, 4 = 누르는 동안 음성 메모. 기지 밖이면 이동 중에도 쓸 수 있고 위치·시각이 자동으로 붙는다. 현장 작업 목록에서는 두 항목을 뺐다. 음성을 쓸 수 없는 환경(보안 연결 아님·권한 거부·마이크 없음)에서는 4가 "시연 예시 메모 · 실제 음성 인식 아님"을 저장한다.
- **선 투영은 HUD에**: 암석 위 3D 선을 끄고, 패키지 선을 "암석을 정면으로 바라봤을 때 보이는 위치"로 계산해 HUD에 고정해 띄운다(가운데 조준점, 채취 예정 지점 원). 고개를 돌려 선이 실제 암석과 겹치면 초록색 "정렬됨"이 되고 버튼 1로 일치 확인. 일치 확인 뒤에는 채취 예정 지점만 암석 위에 강조한다.
- 이동 중 안내가 눈에 잘 안 들어오는 문제는 아직 고민 단계(바꾸지 않음).
- **촬영 모션**: 3을 누르면 뷰파인더 모서리가 잡히고 짧게 번쩍인 뒤, 찍힌 모의 화면이 왼쪽 아래로 작아지며 사라진다("모의 화면 · 실제 카메라 아님").
- **메모는 4 하나**: V 음성 명령에서 "메모"를 뺐다. V는 HUD 조작 명령, 4는 받아쓰기 메모(누르는 동안 말하고 떼면 저장, 예: 채취 이유·표면 모습·다음에 확인할 것).
- **작업 카드 넘침**: 카드 높이를 넘으면 사진·출처 줄을 숨기고, 줄 간격을 줄이고, 그래도 넘치면 선택한 항목 주변과 "복귀 개시"만 보여 주며 "▲/▼ n개 더 · 버튼 2로 이동"을 표시한다(1024×640·1280×720·1440×900에서 확인).
